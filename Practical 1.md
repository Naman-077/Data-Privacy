# Practical 1: Data Privacy Audit of GitHub

## Aim

To conduct a data privacy audit of the **GitHub website** and identify how user data is collected, used, stored, shared, and protected, along with potential privacy risks and recommended privacy measures.

---

## Website Selected

### Organization
**GitHub, Inc.**

### Website
**GitHub**  
https://github.com/

### Privacy Policy
**GitHub General Privacy Statement**  
https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

### Cookies Policy
**GitHub Cookies Policy**  
https://docs.github.com/en/site-policy/privacy-policies/github-cookies

---

## Requirements

- Internet connection
- Web browser
- GitHub account (optional)
- Access to GitHub's Privacy Statement
- Access to GitHub's Cookies Policy

---

## Procedure

1. Visit the **GitHub website**.
2. Open GitHub's **General Privacy Statement**.
3. Identify the types of personal information collected from users.
4. Examine how GitHub uses the collected information.
5. Review the use of **cookies and tracking technologies**.
6. Examine third-party services, integrations, and data sharing.
7. Review GitHub's security and data-retention practices.
8. Identify available privacy controls and user rights.
9. Identify potential privacy risks.
10. Suggest appropriate measures to improve user privacy.

---

## Observations

| Privacy Aspect | Observation | Risk |
|---|---|---|
| **Data Collection** | GitHub may collect account information such as username, name, email address, password, payment information, profile information, and other information provided by users. It may also collect usage, device, IP address, and website interaction data automatically. | **Medium** |
| **User Content** | Information provided through GitHub services may include source code, text, documents, images, feedback, and other user-generated content. | **Medium** |
| **Data Usage** | Collected information may be used to provide and operate GitHub services, maintain security, analyze service performance, communicate with users, and improve services. | **Low** |
| **Cookies & Tracking** | GitHub uses cookies and similar technologies for essential functions, authentication, analytics, performance measurement, and certain advertising or marketing activities. | **Medium** |
| **Third-Party Services** | Third-party integrations, applications, analytics providers, and other services may process information according to their own privacy policies. | **Medium** |
| **Public Information** | Information placed in public repositories, profiles, issues, comments, or other public areas may be accessible to other users. | **Medium** |
| **Security** | GitHub uses administrative, technical, and physical security controls to protect personal data. It also provides security features such as two-factor authentication, passkeys, security logs, and credential-management controls. | **Low** |

## Privacy Risks Identified

- GitHub processes a wide range of personal and technical information, including account, device, IP address, usage, and website-interaction data.

- Public repositories, profiles, issues, comments, and other contributions may expose information that users intentionally publish.

- Cookies and similar tracking technologies can collect information about website usage and interactions.

- Third-party applications and integrations can introduce additional privacy considerations because their own privacy policies may apply to information shared with them.

- Users may unintentionally publish sensitive information such as **passwords, API keys, access tokens, or confidential information** within repositories or other GitHub content.

- Account deletion does not necessarily mean that every piece of information is immediately removed. Certain information may be retained for legal, contractual, security, or other specified purposes.

---

## Recommendations

- Users should avoid publishing **passwords, API keys, access tokens, personal identification information, or confidential information** in repositories.

- Sensitive repositories should be kept **private**, and access should be granted only to authorized users.

- Users should enable **Two-Factor Authentication (2FA)** or **passkeys** to strengthen account security.

- Review installed **third-party applications, OAuth authorizations, extensions, and integrations** regularly.

- Review GitHub's privacy and cookie settings and disable non-essential cookies where appropriate.

- Users should carefully review the information displayed on **public profiles, repositories, issues, pull requests, and comments**.

- Organizations using GitHub should establish appropriate **access-control, data-retention, and privacy policies** for their members.

- Users should regularly review **security logs, personal access tokens, SSH keys, and other credentials** associated with their accounts.

- Users should periodically review GitHub's Privacy Statement because privacy practices and policies may be updated.

---

## Security Measures

GitHub provides several security features that can help protect user accounts and information, including:

- **Two-Factor Authentication (2FA)**
- **Passkeys**
- **Security logs**
- **Personal access token management**
- **SSH key management**
- **Repository access controls**
- **Private repositories**
- **Security alerts and vulnerability features**

These controls can help users reduce unauthorized access and protect sensitive information stored on the platform.

---

## Data Privacy Controls

GitHub provides users with various mechanisms to manage their privacy and security, including:

1. Managing account and profile information.
2. Controlling repository visibility.
3. Managing third-party application access.
4. Managing cookies and tracking preferences.
5. Using two-factor authentication or passkeys.
6. Reviewing account security logs.
7. Managing personal access tokens and SSH keys.
8. Deleting an account when required, subject to GitHub's policies and applicable retention requirements.

---

## Result

The **Data Privacy Audit of GitHub** was successfully performed. The audit examined GitHub's data collection practices, use of personal information, user-generated content, cookies and tracking technologies, third-party services, security controls, data retention, and available privacy controls.

Potential privacy risks were identified, and appropriate recommendations were provided to improve the protection of user data.

---

## Conclusion

GitHub provides a detailed **Privacy Statement** describing how personal data is collected, used, retained, and protected. It also provides information about cookies, third-party processing, authentication, and account-security controls.

However, users should remain careful about the information they publish publicly, the third-party applications they authorize, and the sensitive information stored in repositories.

Following secure authentication practices, maintaining appropriate repository visibility, reviewing privacy settings, and avoiding the publication of confidential information can help reduce privacy and security risks.
